## 2026-11-06 全量优化（契约 v1）：范围与验证

- **依据**：[全量优化实施契约 v1](20261106_全量优化实施契约_v1.md)。A 页面逻辑/文案、B 样式与日历键盘语义、C 标签口径/测试/文档三线并行，Lead 负责备份、协调、最终 diff 与全套验证；不改动写盘语义、路径护栏、写前备份、写队列与 `date/anchor` 分离。
- **本轮方向**：状态与错误态收敛为一条状态条 + 可重试提示；删除守卫、busy 拆分与逐条 pending；日历 `aria-modal`、`role=row` / `role=gridcell` 与 roving tabindex；库切换失败回滚；900px 自动折叠并给可见提示；主题色改用宿主 `--dsw-alias-*` 与 `color-mix()`。**标签口径统一为只统计未完成任务**，与年 / 月 / 日的未完成计数一致。
- **A / B / C 均已完成**：A 完成状态条、删除守卫、busy 拆分/逐条 pending、timeline 失败降级、月/年 `listDate`、库选择器与 `aria-modal`；B 完成宿主主题 token、状态条样式、日历 `role=row`/`role=gridcell` 与 roving tabindex；C 完成标签口径、测试、文档与离线回归。

- **验证结果**：`pnpm build` 双产物就位；`pnpm typecheck` 两端通过；`pnpm test` 80 项通过（5 个 suite）；`pnpm test:e2e` ALL PASS；`pnpm test:client` 契约 10 项 + 离线浏览器 9 项真实交互全部 PASS。深色 / 浅色 / 820px 窄屏截图见 `screenshots/20261106_任务看板全量优化_dark.png` 与 `..._light.png`。修改前备份保留在 `~/tmp/2026-11-06_full-optimization-backup`。

## 2026-11-07 待安排（Inbox）功能：确认的默认

- **依据**：用户提出「增加一个没有时间的任务，保存在独立文件里」，并对四个设计选择逐一确认。
- **确认项**：① 文件与日记同级，即 `20 Daily/Inbox.md`（可用 `inboxFile` 覆盖）；② 「全部」视图包含待安排任务；③ 允许日期任务「移回待安排」；④ 添加目标升级为「待安排 / 今天 / 明天 / 后天 / 选择日期…」菜单。
- **口径**：Inbox 不进年 / 月 / 日时间线；「全部」= 日期未完成 + Inbox 未完成；「已完成」含 Inbox 已完成；标签统计包含 Inbox 未完成任务。
- **验证**：`pnpm build` / `pnpm typecheck` / `pnpm test`（94 项）/ `pnpm test:e2e`（ALL PASS）/ `pnpm test:client`（16 项浏览器交互全 PASS）。预览见 `docs/screenshots/20261107_待安排视图_v1.png`、`docs/screenshots/20261107_添加目标菜单_v1.png`。
